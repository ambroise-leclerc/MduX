# ISO 13485:2016 §6 — Resource management

Like §5, this clause is mostly about an organization's own staffing, competence, and physical
facilities — provision of resources, human resources, infrastructure, and a controlled work
environment. MduX has no employees, no facility, and no manufacturing environment of its own; this
clause has essentially no MduX-specific mechanism to cite, and this corpus states that rather than
inventing one.

## §6.1–§6.2 Provision of resources, human resources

No MduX-specific mechanism. Competence of the people who develop MduX is not something this
repository can attest to about itself.

## §6.3 Infrastructure

The one narrow, honest analog: this project's build infrastructure (CMake presets, the CI matrix
across MSVC/GCC/Clang) is itself version-controlled and reviewed the same way source code is,
which is a form of infrastructure control — but it is build infrastructure, not the facilities and
equipment this clause is actually about.

## §6.4 Work environment and contamination control

No MduX-specific mechanism. This sub-clause concerns a manufacturer's physical work environment,
which has no software analog.
